# backdoor-audit — 图像分类模型后门排查工具

针对"外购模型可能被投毒（BadNets 式触发器后门）"的场景：**只拿到模型文件、没有任何训练数据**，
反推可能存在的触发图案及其目标类别，判断模型是否被植入后门，并尝试清除后门、评估对正常准确率的影响。

## 方法（Neural Cleanse, Gu et al. 2019）

1. **类别图像反演**（代替训练数据）：从随机噪声出发，用梯度上升优化输入图，使模型高置信地判为类别 c，
   加全变差（TV）正则让图像分段平滑。每个类别合成 n 张"基图"。
2. **触发器反推**：对每个候选目标类 t，联合优化掩码 m ∈ [0,1]^(H×W) 与图案 p：
   `x' = (1-m)·x + m·p`，最小化 `CE(model(x'), t) + λ·‖m‖₁`。
   基图取**其他类别**的合成图（若用 t 类自身图片，"攻击"会平凡成功——这是实现上的关键坑）。
   直觉：把任意人识别成"指定身份"所需的最小改动，真实后门只需要一个极小图案；
   而良性模型要翻转类别必须改动大面积语义区域。
3. **判定**（双准则）：
   - 主准则：各类别 ‖m‖₁ 的 MAD 离群指数 = |x − median| / (1.4826·MAD) > 2 且为**偏小**离群；
   - 辅助准则（相对间隙）：类别数少时 MAD 噪声大，若最小 ‖m‖₁ < 0.7 × 其余类中位数且反推 ASR ≥ 0.95 也判后门。
     对照实验中该比值干净模型 ≈ 0.8–0.9、投毒模型 ≈ 0.55–0.6，分离稳定。
4. **清除（两档）**：
   - **A. 纯模型反学习**：用反推触发器贴到各类合成图上、标真实标签微调。无需任何数据，
     但合成图与真实分布有差距，效果有限（实测 ASR 只能部分压降）；
   - **B. 少量干净数据反学习**（推荐，NC 论文标准协议）：部署方通常能收集少量干净样本，
     20% 贴上反推触发器、标真实标签微调 1 个 epoch（2000 张即可），ASR 可压到个位数且干净准确率基本不变。

## 搜索策略的取舍

- **全量扫描**：代价 O(N) 次触发器优化（N=类别数）。MNIST（10 类）秒级；人脸门禁 N 上千时不可行。
- **由粗到细**：`scan` 子命令支持 `--classes-start/--classes-end` 只扫子集；实践上可先随机抽 5–10% 类别
  估计良性 L1 基线，再对可疑类精扫（加大 `--synth-steps/--opt-steps`）。
- **λ（L1 惩罚）是核心超参**：太小 → 掩码不压缩，所有类都差不多大，漏报；太大 → 良性类也被压成小掩码，误报。
  代码默认 lam=1e-3，建议按"良性类 L1 稳定、后门类显著更小"的区间网格搜索（见下）。

## 用法

```bash
pip install torch torchvision

# 完整对照实验：训练干净模型 + BadNets 投毒模型 → 扫描两者 → 清除后门 → 评估
python -m backdoor_audit.run_all demo

# 只审计一个已有模型文件（无需任何数据）
python -m backdoor_audit.run_all scan --model checkpoints/backdoored.pt \
    --n-base 32 --synth-steps 300 --opt-steps 300
```

输出：每类的 L1 范数与异常指数、判定结论、反推触发器图像（`reports/*.png`）、
清除前后的干净准确率 / 真实触发器 ASR / 反推触发器 ASR 对照表。

## 对照实验设计与实测结果

- **干净模型**：MNIST 正常训练 3 epoch（acc = 98.67%）。
- **投毒模型**：10% 训练样本右下角贴 4×4 白色方块、标签改为 0（BadNets），
  干净准确率几乎不降（98.57%），但真实触发器 ASR = 99.98% —— 说明仅靠精度测试无法发现后门。

实测（`python -m backdoor_audit.run_all demo`）：

| 模型 | 判定 | 关键证据 |
|---|---|---|
| 干净模型 | ✅ 无后门 | 各类 L1 ∈ [105, 198]，最小/其余中位数 ≈ 0.80，无离群 |
| 投毒模型 | 🚨 后门，目标类 = 0 | 类 0 的 L1 = 86（其余类 123–242），比值 0.57 < 0.7，反推 ASR 99% |

反推出的触发器 mask 高响应像素集中在 (24–27, 24–27) —— 正是真实触发器位置（比真实图案稍弥散）。

清除效果（2000 张干净样本 + 反推触发器增强，5 epoch）：

| 模型 | 干净准确率 | ASR（真实触发器） | ASR（反推触发器） |
|---|---|---|---|
| 投毒模型（清除前） | 98.57% | 99.98% | — |
| A：纯模型反学习 | 89.44% | 55.4% | 96.3% |
| **B：少量干净数据反学习** | **97.98%** | **0.73%** | **1.78%** |

结论：纯模型反学习（A）只能部分压降 ASR 且损伤准确率——合成图与真实分布的差距限制了迁移；
有少量干净样本时（B）后门基本清除且准确率损失 < 1 个点。检测环节本身完全不需要数据。

## 局限

- 针对**补丁式（patch）触发器**；对全图扰动式（如 WaNet、混合式）触发器，L1 最小化假设不成立，可能漏报。
- 合成基图质量影响反推效果；复杂数据集（人脸）建议增大 `--n-base` 与合成步数，或用少量真实测试图替代合成图。
- MAD 阈值 2 是经验值；类别数很少时统计功效不足，应结合反推 ASR 与 L1 绝对值人工复核。
- 反学习清除对"反推≈真实"触发器有效；若攻击者用多个触发器或全图触发器，建议叠加 fine-pruning。
